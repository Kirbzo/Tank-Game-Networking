ISSUE FOUND AND FIXED
The original wildcard UDP broadcast used the default adapter instead of the
host-only LAN. The baseline passed only direct-IP lookup (2 of 6 cases).
Godot/discovery.gd now creates broadcast senders bound to each eligible local
IPv4 address and receives query replies on those sockets. It retains the
existing listening ports, loopback discovery and IPv4 fallback.
One subsequent automatic-mode expiry test timed out while the slow VM's
fixed-duration host was still running. The test controller was changed to
request host shutdown after receiving the real remote listing. The targeted
Linux-host automatic-discovery/expiry rerun passed. Five other cases had
already passed with the same fixed discovery code; their evidence is retained.
