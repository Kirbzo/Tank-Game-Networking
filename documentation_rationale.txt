Documentation choices
README.md follows the PDF's project name and purpose. It separates the October 20, 2026 
alpha lobby demonstration from the framework requirements because the PDF permits simulated 
joining during the alpha while requiring real networking for the framework. Tables preserve 
each requirement ID and its acceptance criteria for review.

The target folder was empty when inspected. The README therefore describes required and intended
 behavior and explicitly states that no runnable implementation is present. Setup commands, 
 ports, controls, and scene names were not invented because the source does not specify them.

AGENTS.md translates the PDF's constraints into practical instructions for future agents. 
It also records the user's folder boundary, protects the source PDF, and limits the current task 
to the three requested documentation files. Future implementation requires a later user request.

Start permissions, movement/action rules, and the match-end trigger remain decisions for the 
team. They were documented as unresolved rather than assigned arbitrary values.
